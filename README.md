# Demso

Demso is a crowdfunding and payout platform tailored for Francophone Africa, supporting Mobile Money and bank card payment flows. The project is currently in active development.

## Tech Stack
- **Backend:** Go (Gin), REST APIs, idempotency handling for transactions
- **Cloud & Frontend:** AWS (DynamoDB, API Gateway, Lambda, S3, IAM), React, Vite
- **In Progress:** Docker and Terraform for containerization and cloud provisioning

## Project Status
Core backend services, payment/payout workflows, and frontend screens are actively being built and refined, while Docker and Terraform setup is still in progress.
